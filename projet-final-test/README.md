# SAS Progress Console

Application Console en JavaScript (Node.js) permettant de gérer les apprenants, calculer leur progression et afficher un tableau de bord pédagogique.

## Structure du projet
- `src/data.js` : Données de départ des apprenants.
- `src/index.js` : Logique métier, fonctions de calcul et interface menu console.
- `tests/scenarios.js` : Scénarios de tests automatiques.
